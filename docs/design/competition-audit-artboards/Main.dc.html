What four established systems taught us about our own requirements

Four document management systems, read from administrator documentation and published service limits rather than marketing pages. The audit moved our requirement set from 106 to 168 — and every change below is traceable to a documented statement, linked in the repository.

Confirmed — the market builds it the way we specified

Confirmed

One document, many dossiers

A German ECM platform models this as n:m and states it plainly: documents live in several logical dossiers "ohne sie dabei redundant zu halten". Its example is an invoice in both the order and the customer dossier.

DOS-U-6
Confirmed

Restore creates a new version

A metadata-driven DMS documents rollback as creating a new version from the selected one, with no effect on the versions in between. History is never rewritten.

UPL-12
Confirmed

Filter and sort span the whole set

A collaboration platform caps views at 5,000 items, unchangeable. Above it, filters and sorts return partial results. Our requirement's failure mode, shipped at scale.

FLT-14 SRT-12

Gaps — what everyone has and we had missed

Was missing

Automatic filing by metadata rule

The system files a document into an existing dossier, or creates one, from its metadata. We had specified only manual filing. In a working system most filing is automatic.

DOS-U-17 DOS-U-20 DOS-A-20
Was missing

A file plan above dossier types

An organisation-wide classification scheme — for filing a new dossier in the right place and finding an existing one. Workable without at ten dossiers; not at several hundred.

DOS-A-23 DOS-A-24
Was missing

Text extraction and OCR

We required full-text search and metadata proposed from document content, without ever requiring the extraction that makes either possible.

UPL-21 UPL-23

Stricter — held deliberately

We refuse

Retention proposes; it never deletes

A compliance-focused DMS markets automatic secure deletion once retention lapses. Ours moves the document into a review queue and destroys nothing without an audited human decision.

DOS-A-13 RET-12
Our advantage

Every export carries a manifest

No system audited documents one. Independent reviews flag the absence as a purchasing risk: no practical bulk export of documents, metadata and version history for offboarding.

BDL-8 BDL-4

What this audit does not settle

Two of the four take opposite positions on the question our architecture work has open — whether the front door is the dossier or the document library — and both ship successfully. The metadata-driven DMS has no folders at all; the German platform's file plan and automatic filing win where completeness of the case file is what gets audited. That choice is ours, and the audit does not make it.
